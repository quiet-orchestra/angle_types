#Angle Types

This is the Angle Types crate. It allows you to freely specify angles in terms of degrees, radians, and turns, use all the associated trig functions with them, and do basic arithmetic functions like adding angles of different types or multiplying them. 

by Quiet Orchestra

Use of LLMs as a research tool is allowed, but directly copying anything larger than a snippet or using a cursor-like tools outside of testing sections is prohibited in this repo.
